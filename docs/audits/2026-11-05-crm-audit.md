# CRM audit — 2026-11-05

**Scope:** Drivers, My Duties, Invoices, and the whole CRM: data sync, database tables, security, code and performance.

**Method:**
- Code review.
- Read-only checks of live Supabase (row counts and column names only) and of the live VPS API (status codes and sizes only).
- `npm run check` and a production build.
- Nothing was tested in a browser.

Status: **Fixed** = changed in this round (commits up to `main` on 2026-11-05). **Open** = still to do; the priority list is at the end.

## 1. Is the data live and in Supabase?

| Data | Where it lives | Verdict |
|---|---|---|
| Bookings, clients, employees, daily jobs, expenses, invoices, inventory | Supabase tables. Each change goes through the outbox (retried, sent live to other users). | Live. Counts on 2026-11-05: 5 bookings, 4 clients, **32 employees** (30 cleaners added automatically by R-EMP-06), 118 jobs, 2 invoices. |
| Attendance marks | Supabase table `attendance_marks` | Live (10 marks) |
| Settings-type lists (contracts, payments, budgets, closed days, Excel colours, driver plans …) | 30 `app_state` keys, cloud-synced | Live |
| **Agencies** | VPS JSON file **and** Supabase | **Was not in Supabase**: the table had 0 rows, the VPS file 4. Agencies made before the sync existed only on the VPS, and edits only *updated* a row that did not exist. **Fixed (AGN-A01):** copied to Supabase on the next admin / manager sign-in. |
| Company info | `company_settings` table (browser keeps a cache) | Live |
| Sidebar, column layouts, view modes, theme | Browser only | Intended: personal screen settings |
| Leads (Fluent Forms) | VPS file + Supabase `fluent_form_leads` | Live |

**No business data stays only on one device.** The browser copies (`safaeewala_*`) are caches. Supabase is the source.

## 2. Security

| ID | Severity | Finding | Status |
|---|---|---|---|
| SEC-A01 | **Critical** | Without the service key on the VPS (K-06), every `/api` route was open to the internet. Anyone could read all **leads** (names, phones, addresses: 30 KB), **agencies** (contacts, document list) and the **error log** (69 KB). | **Fixed (R-SEC-06):** the server now checks the sign-in with the public key. Only a lead from Fluent Forms and an error report may be sent without one. |
| SEC-A02 | High | The VPS still has no `SUPABASE_SERVICE_ROLE_KEY` and no `FLUENT_WEBHOOK_SECRET`. Settings → Users cannot add logins, and anyone can post fake leads. | **Open: owner action** (approval list) |
| SEC-A03 | High | Field logins (cleaners / drivers) are limited to My Duties **in the app only**. With their token they could still read every table (clients' phones, money) straight from Supabase, because the row rules allow every active user. | Open: needs SQL row rules per role (approval list) |
| SEC-A04 | Medium | The Content-Security-Policy in `nginx.conf` is *report-only*, so it blocks nothing yet. | Open: switch to enforcing after a quiet week |
| SEC-A05 | Medium | No database rule keeps invoice numbers unique. The app now checks Supabase first (INV-A01), but a unique index would make it certain. | Open: SQL (approval list) |
| SEC-A06 | Low | Profile photos are stored as data URLs in the employee row (EMP-07). | Open |

## 3. Invoices

| ID | Severity | Finding | Status |
|---|---|---|---|
| INV-A01 | High | The next number was counted from the invoices in **this browser only**. Two users, or two tabs, creating an invoice together got the **same tax invoice number**. Booking auto-invoices had the same race. | **Fixed:** the numbers in Supabase are read before saving and the next free one is used. |
| INV-A02 | Low | The number's year came from the computer clock, not Dubai. | **Fixed** |
| INV-A03 | Medium | *Overdue* was set only when the Invoices page opened with the list already loaded. On a fresh load the list was still empty, so nothing became overdue. | **Fixed:** runs again when invoices arrive. |
| INV-A04 | Low | The date filter used the UTC date: an invoice made after 8 PM Dubai counted as the next day. | **Fixed** |
| INV-A05 | Medium | The *Overdue* total counted the full amount even when part was paid. | **Fixed:** the balance is used. |
| INV-A06 | Low | The default due date was +10 days in UTC. | **Fixed:** Dubai date |
| INV-A07 | Medium | An issued (sent / paid) tax invoice could be deleted with the same message as a draft. UAE VAT rules expect issued invoices to be kept (a credit note cancels them). | **Partly fixed:** a clear warning. Blocking it, or adding *Void / Credit note*, is in the approval list. |
| INV-A08 | Low | *VAT collected* counts only fully paid invoices. Part payments' VAT is not shown. | Open: accounting choice (cash basis) |

Live check: 2 invoices (SAF-2026-0001 paid, SAF-2026-0002 draft). The numbers are unique and the totals are consistent (subtotal + 5% VAT).

## 5. Code, performance, scalability

| ID | Finding | Suggestion |
|---|---|---|
| CODE-A01 | Five screens are over 3,500 lines (Excel Job Sheet 6,516, Daily Job Sheet 4,437, Bookings, Agency dashboard, Monthly Clients). They are hard to change safely. | Split by part (toolbar, grid, popups, save logic) into `src/components/<area>/`. Start with the Excel Job Sheet. |
| CODE-A02 | 752 lint warnings, 252 `any` casts. | Fix them screen by screen while splitting; turn key rules into errors. |
| PERF-A01 | Every table is loaded in full at start-up (all jobs ever). Fine at 118 jobs; slow at tens of thousands. | Load the last 90 days; older history on demand (date window). |
| PERF-A02 | Per-employee statistics scan every job for every employee (EMP-06). | Build one cleaner → jobs index in `DataContext` and reuse it. |
| PERF-A03 | Largest downloads: Excel library 425 KB, charts 377 KB, Daily Job Sheet 279 KB. | Load the Excel library only when importing / exporting (dynamic import). |
| SCALE-A01 | Settings-like data in `app_state` keys is one JSON value per key: last writer wins. | Move busy keys (driver plans, payments, contracts) to their own tables, as done for attendance. |
| SCALE-A02 | Agencies live in two stores (VPS file + Supabase). | After AGN-A01 has run, make Supabase the only store. |
