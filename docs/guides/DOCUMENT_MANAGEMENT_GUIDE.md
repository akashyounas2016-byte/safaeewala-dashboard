## Part 1: Quick Start

### Step 1: Upload a Document
1. Go to **Operations** → **Documents**
2. Click **"+ Upload Document"**
3. Select file (PDF, DOCX, XLSX, images)
4. Fill in document details:
   - **Name**: Descriptive title
   - **Type**: Contract, Agreement, Certification, Compliance, Financial
   - **Category**: Client, Employee, Company, Legal
   - **Linked To**: (Optional) Client or employee name
   - **Expiration Date**: (Optional) For compliance tracking
5. Click **Save**

### Step 2: Track Documents
- **View all documents** in the table
- **Search** by name or linked party
- **Filter** by type or category
- **Sort** by status, expiration, etc.

### Step 3: View Details
- Click the **eye icon** on any document
- See full details including:
  - Upload date
  - Expiration status
  - Signature info
  - Access history
- **Download** document as needed

## Part 3: Digital Signatures

### How to Sign a Document

**Client Signature:**
1. Open document in dashboard
2. Click "Request Signature"
3. System generates secure link
4. Send to client email
5. Client signs electronically
6. Signature recorded with timestamp

**Admin Signature:**
1. Open document
2. Click "Sign"
3. Draw signature or upload image
4. Confirm and save
5. Timestamp recorded automatically

### Signature Benefits
- ✅ Legally binding
- ✅ Timestamped
- ✅ Non-repudiation (can't deny signing)
- ✅ Audit trail
- ✅ Electronic record

### What Gets Signed
- Client service agreements
- Recurring contracts
- Liability waivers
- Terms & conditions
- Payment authorizations
- NDA documents

## Part 4: Expiration Tracking

### Setting Expiration Dates
When uploading, specify expiration date for:
- Contracts (annual renewal)
- Certifications (when they expire)
- Licenses (renewal dates)
- Insurance (policy renewal)
- Compliance docs (regulatory dates)

### Automatic Alerts
Dashboard monitors expiration dates:
- **30 days before**: "Expiring Soon" warning
- **On expiration date**: "Expired" alert
- **After expiration**: Compliance issue flagged

### Alert Response
1. **See alert** on dashboard
2. **Review document** details
3. **Renew or update** the document
4. **Upload new version**
5. **Alert clears** automatically

## Part 5: Access Logs & Audit Trails

### Who Accessed What
Every document tracks:
- **User**: Who accessed it
- **Action**: Viewed, Downloaded, Signed, Shared
- **Timestamp**: Exact date and time
- **IP Address**: (Optional) For security

### Example Access Log
```

Akash Younas - Downloaded - 2026-06-05 2:22 PM
Ahmed Al Mansoori - Signed - 2026-05-20 11:15 AM
Fatima Al Mazrouei - Viewed - 2026-05-18 3:45 PM
```

### Compliance Benefits

- ✅ Track who has access
- ✅ Detect unauthorized access
- ✅ Maintain regulatory compliance
- ✅ Dispute resolution evidence

## Part 10: Cloud Storage Integration

### Option A: AWS S3
```typescript
// Configure S3 bucket
const AWS = require('aws-sdk');
const s3 = new AWS.S3({
  accessKeyId: process.env.AWS_ACCESS_KEY_ID,
  secretAccessKey: process.env.AWS_SECRET_ACCESS_KEY,
});

// Upload document
const params = {
  Bucket: 'safaeewala-documents',
  Key: `documents/${docId}/${filename}`,
  Body: fileBuffer,
  ServerSideEncryption: 'AES256',
  Metadata: {
    'owner': clientName,
    'type': docType,
  }
};

const result = await s3.upload(params).promise();
```

### Option B: Firebase Storage
```typescript
// Configure Firebase
import { storage } from '@/lib/firebase';
import { ref, uploadBytes, getDownloadURL } from 'firebase/storage';

// Upload document
const docRef = ref(storage, `documents/${docId}/${filename}`);
const snapshot = await uploadBytes(docRef, file);
const downloadUrl = await getDownloadURL(snapshot.ref);
```

### Option C: Supabase Storage
```typescript
// Use Supabase built-in storage
const { data, error } = await supabase.storage
  .from('documents')
  .upload(`documents/${docId}/${filename}`, file, {
    cacheControl: '3600',
    upsert: false,
    metadata: {
      owner: clientName,
      type: docType,
    }
  });
```

## Part 13: Troubleshooting

| Issue | Solution |
|-------|----------|
| Document too large | Keep under 50MB; use PDF instead of image scans |
| Can't upload type | Use PDF, DOCX, XLSX, JPG, PNG only |
| Signature not working | Ensure client has email access; resend link |
| Access denied | Check user permissions; verify document sharing |
| Expiration alert not showing | Ensure expiration date is set; refresh page |
| Can't find document | Use search/filter; check category and type |
