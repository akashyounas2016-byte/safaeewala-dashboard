2. WHAT IS BEING BUILT
--------------------------------------------------------------

A web-based internal management dashboard (not client-facing).
Only Akash (owner) and admin staff will use it.

Purpose: Replace manual WhatsApp/Excel management with a
single tool for running the entire cleaning business.

Tech stack (for context, not for the designer to worry about):
  - React 19 + TypeScript
  - Tailwind CSS (utility-first CSS framework)
  - Runs in a browser at http://localhost:5173 during dev
  - Responsive: works on desktop and tablet (mobile is secondary)

Layout structure:
  - Left sidebar (fixed, always visible on desktop, 240px wide)
  - Top header bar (fixed, full width)
  - Main content area (scrollable, max ~1280px wide, centered)


--------------------------------------------------------------
3. CURRENT PROBLEMS (Why a designer is needed)
--------------------------------------------------------------

The current implementation was built by a developer without
professional design input. Issues:

  a) No consistent visual hierarchy — everything looks the same weight
  b) Color scheme feels amateurish — too many greens, no clear system
  c) Cards have inconsistent padding (some cramped, some too spaced)
  d) Typography has no clear size scale — headings vs body feel similar
  e) KPI metric cards are merged into a gray strip — not individual,
     feels like a spreadsheet
  f) The sidebar feels dark but inconsistent — active states unclear
  g) Charts lack proper labeling and visual breathing room
  h) The overall feel is "developer-designed" — not polished or modern
  i) No clear design language across pages — each page looks different


--------------------------------------------------------------
4. DESIGN GOALS
--------------------------------------------------------------

  - Clean, modern, professional SaaS dashboard aesthetic
  - Primary users: owner + 1-2 admin staff (not tech-savvy)
  - Should feel premium — this is for a growing Dubai business
  - Clarity over decoration — data must be easy to scan quickly
  - Consistent spacing, consistent card padding, consistent type scale
  - Brand color: Deep Emerald / Dark Green (company name = "Safaeewala"
    which means "cleaner" in Urdu/Hindi)
  - No clutter. White space is not empty space — use it well.

--------------------------------------------------------------
8. TYPOGRAPHY REQUIREMENTS
--------------------------------------------------------------

The designer should define a clear type scale:

  Recommended font: Inter (already installed)

  Suggested scale:
    H1 (page title in header)   : 16–18px, semibold
    H2 (section title in page)  : 20–24px, bold
    H3 (card title)             : 14–16px, semibold
    KPI number                  : 28–32px, bold, tight tracking
    Body text                   : 13–14px, regular
    Small / label               : 11–12px, medium or semibold
    Uppercase label             : 10–11px, semibold, wide tracking

  Key rule: There must be a clear visual gap between heading sizes.
  Currently all sizes feel too close together.

9. SPACING & LAYOUT REQUIREMENTS
--------------------------------------------------------------

  Sidebar width     : 240px (fixed)
  Header height     : 60–64px (fixed)
  Content max-width : 1280px (centered)

  Currently some cards have tight content touching the edges.
